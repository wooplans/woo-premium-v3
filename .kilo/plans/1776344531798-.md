# Plan : Catalogue de Plans Architecturaux - Duplex & Villa

## Stack Technique
- **Framework** : Next.js 14+ (App Router)
- **Base de données** : Cloudflare D1 (SQLite edge)
- **ORM** : Drizzle ORM (optimisé pour D1)
- **Stockage fichiers** : Cloudflare R2
- **Styling** : Tailwind CSS
- **Déploiement** : Cloudflare Pages
- **Runtime** : @cloudflare/next-on-pages

## Schéma de la base de données

### Table `plans`
| Colonne | Type | Description |
|---------|------|-------------|
| id | TEXT (UUID) | Clé primaire |
| title | TEXT | Titre du plan |
| type | TEXT | "duplex" ou "villa" |
| description | TEXT | Description détaillée |
| surface | INTEGER | Surface en m² |
| bedrooms | INTEGER | Nombre de chambres |
| bathrooms | INTEGER | Nombre de salles de bain |
| floors | INTEGER | Nombre d'étages |
| price | REAL | Prix en FCFA (ou autre devise) |
| features | TEXT (JSON) | Liste de caractéristiques |
| thumbnail | TEXT | URL de l'image principale |
| images | TEXT (JSON) | Liste des URLs des images |
| is_published | INTEGER | 0=brouillon, 1=publié |
| created_at | TEXT | Date de création |
| updated_at | TEXT | Date de mise à jour |

## Pages et fonctionnalités

### 1. Catalogue public (`/`)
- Grille de cartes de plans avec image miniature
- Filtres : type (duplex/villa), surface, nombre de chambres, prix
- Seuls les plans publiés (`is_published = 1`) sont affichés

### 2. Page détail (`/plans/[id]`)
- Galerie d'images du plan
- Informations complètes : titre, type, surface, chambres, salles de bain, étages, prix
- Description détaillée
- Liste des caractéristiques (features)
- Bouton retour au catalogue

### 3. Dashboard Admin (`/admin`)
- Liste de tous les plans (publiés et brouillons) dans un tableau
- Actions : créer, éditer, supprimer, publier/dépublier
- Statut visuel (publié/brouillon)

### 4. Formulaire Admin (`/admin/plans/new` et `/admin/plans/[id]/edit`)
- Champs : titre, type (select), description (textarea), surface, chambres, salles de bain, étages, prix
- Upload de multiples images via R2
- Sélection de l'image miniature
- Ajout de caractéristiques (features) dynamiques
- Toggle publier/brouillon

## API Routes

| Méthode | Route | Description |
|---------|-------|-------------|
| GET | `/api/plans` | Liste des plans (filtres optionnels : type, published) |
| POST | `/api/plans` | Créer un plan |
| GET | `/api/plans/[id]` | Détail d'un plan |
| PUT | `/api/plans/[id]` | Mettre à jour un plan |
| DELETE | `/api/plans/[id]` | Supprimer un plan |
| POST | `/api/upload` | Upload image vers R2 |
| DELETE | `/api/upload` | Supprimer image de R2 |

## Étapes d'implémentation

1. **Initialisation du projet** : `npx create-next-app`, installer dépendances (drizzle-orm, @aws-sdk/client-s3 pour R2, etc.)
2. **Configuration Cloudflare** : `wrangler.toml` avec D1 et R2 bindings
3. **Schéma DB et migrations** : Définir le schéma Drizzle et générer les migrations
4. **Librairies utilitaires** : Client R2, connexion DB, types
5. **API Routes** : CRUD plans + upload R2
6. **Composants UI** : PlanCard, PlanGallery, PlanForm, ImageUpload, Navbar
7. **Pages publiques** : Catalogue avec filtres + page détail
8. **Pages admin** : Dashboard, formulaires création/édition
9. **Polish** : Responsive, loading states, gestion d'erreurs

## Notes
- Pas d'authentification en V1 (à ajouter dans une V2)
- Les images sont stockées dans Cloudflare R2 et servies via URL publique
- Drizzle ORM est utilisé car il a un support natif de Cloudflare D1
- Le projet sera déployable sur Cloudflare Pages
